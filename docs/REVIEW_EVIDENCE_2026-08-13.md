## Changes made after evidence collection

The minimal Hybrid IR increment adds an internal conversion from successful recovery-parser ASTs to an ordered variant sequence of declarations, quantum gates, and measurements. It preserves span, literal, and gate fields and rejects retained legacy `InstructionNode` values with `SYNQ-H001` rather than creating a partial program. [Compiler Core #23](https://github.com/TangoSplicer/SynQ/actions/runs/31803349469) passed for revision `772ede7`, including the fourteenth `synq_hybrid_ir_smoke` CTest check; the manual repeat [Compiler Core #24](https://github.com/TangoSplicer/SynQ/actions/runs/31803368082) also passed. This evidence covers the small internal conversion only, not name resolution, type checking, execution, or control flow.

The bounded scoped-name-resolution increment adds a sequential top-level pass over the minimal Hybrid IR. It resolves only whole-identifier declaration initializers to earlier declaration indices; opaque expression-like source text remains unresolved by design, and unknown or forward identifiers return `SYNQ-R001` with the referring span. [Compiler Core #26](https://github.com/TangoSplicer/SynQ/actions/runs/31803737501) passed for revision `34bd685`, including the fifteenth `synq_name_resolution_smoke` CTest check. This does not establish nested lexical scopes, modules, imports, expression resolution, type checking, assignment, or control flow.

The bounded classical-control-flow increment registers an Alpha `classical-control-flow` feature. With the required opt-in, it parses only literal-boolean `if ... then ...` and `while ... do ...` statements with one typed quantum-gate or measurement body, carries them through the AST/Hybrid IR, and preserves them through the bounded resolver. It rejects malformed structure with `SYNQ-P009` and unsupported bodies with `SYNQ-P010`; it does not execute or lower control flow. [Compiler Core #27](https://github.com/TangoSplicer/SynQ/actions/runs/31804184422) passed for revision `2121c2f`, including the sixteenth `synq_classical_control_flow_smoke` CTest check; manual repeat [Compiler Core #28](https://github.com/TangoSplicer/SynQ/actions/runs/31804191932) also passed.
