# Historical Keyring Notice

**Status:** Retired as a security or API reference on 20 August 2026.

This page formerly described an unsupported federated keyring, plugin quorum,
REPL commands, remote synchronization, and a Python API. Those facilities are
not part of the verified SynQ recovery compiler or its experimental C ABI.
The unsupported example has been removed to prevent readers from treating it as
current language or security guidance.

For the repository’s current vulnerability-reporting route, read
[`SECURITY.md`](../../SECURITY.md). For experimental compiler and ABI boundaries,
read [`docs/PROJECT_STATUS.md`](../../docs/PROJECT_STATUS.md),
[`docs/C_ABI.md`](../../docs/C_ABI.md), and
[`docs/KNOWN_LIMITS_v0.1.0.md`](../../docs/KNOWN_LIMITS_v0.1.0.md).
